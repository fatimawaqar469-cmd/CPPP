# 📚 Library Management System (C++)

A simple console-based Library Management System built in C++ using file handling. This project helps manage books in a library, including adding, issuing, returning, and searching books.

---

## 📌 Features

- Add new books to the library
- Display all available books
- Search book by ID
- Issue a book to a student
- Return a book with fine calculation
- File-based data storage (`library.txt`)

---

## 🛠️ Technologies Used

- C++
- File Handling (`fstream`)
- Object-Oriented Programming (OOP)
- Console Application
